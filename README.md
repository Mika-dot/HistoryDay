# HistoryDay — «История дня»

> **Минималистичный Android-видеодневник.** Несколько случайных двухсекундных фрагментов в течение дня автоматически превращаются в короткую видеоисторию.

## Что это

Обычный видеодневник требует помнить о съёмке и специально выбирать, что сохранить. HistoryDay работает наоборот: приложение само один раз в случайный момент каждого часа напоминает о записи.

Нажатие на уведомление запускает камеру, автоматически записывает **2 секунды** и закрывает экран. В конце дня фрагменты можно собрать в единый ролик.

```text
случайное уведомление
        ↓
      1 тап
        ↓
автоматическая запись 2 сек
        ↓
   локальное сохранение
        ↓
   история текущего дня
        ↓
     дневной ролик
```

Главная идея — сохранить случайные срезы обычной жизни, а не постановочную подборку лучших моментов.

## Основной сценарий

1. Включить HistoryDay.
2. Получить уведомление в случайную минуту часа.
3. Нажать на него.
4. Камера сама запишет 2 секунды.
5. Продолжить заниматься своими делами.
6. Позже открыть день и посмотреть отдельные моменты или весь ролик.

Никаких аккаунтов, публикаций, лент и обязательной синхронизации.

## Возможности 1.5

### Автоматические 2-секундные моменты

- одно случайное напоминание каждый час;
- стандартный активный интервал `08:00–22:59`;
- запись начинается сразу после нажатия на уведомление;
- длительность момента — 2 секунды;
- фронтальная камера по умолчанию;
- переключение на заднюю камеру в один тап;
- выбор камеры сохраняется;
- фронтальное видео зеркалируется;
- приоритет FHD с автоматическим fallback на HD/SD;
- звук записывается при наличии разрешения на микрофон.

### Быстрые действия уведомления

Если момент сейчас неудобен:

- **Через 10 минут** — перенести текущее напоминание;
- **Пропустить** — убрать его и продолжить обычное расписание со следующего часа.

Для этого нет отдельного сложного планировщика.

### История дня

Каждый день содержит:

- все сохранённые моменты;
- точное время каждого клипа;
- горизонтальную шкалу моментов;
- последовательный таймлайн;
- воспроизведение отдельного 2-секундного фрагмента;
- количество моментов;
- место и координаты, если разрешена геолокация;
- лёгкую схему последовательности геоточек;
- итоговый дневной ролик;
- повторную сборку ролика;
- отправку готового MP4 через стандартное меню Android.

### География без тяжёлой карты

HistoryDay не тащит внутрь Google Maps, `osmdroid`, Yandex MapKit или 2GIS SDK.

При записи клипа приложение может сохранить координату. Название места определяется системным Android `Geocoder`, если он доступен.

Внутри дня показывается лёгкая локальная схема расположения точек без загрузки картографических тайлов.

Для полноценной карты используется кнопка **«Открыть точку в картах»**:

```text
HistoryDay → Android geo: intent → установленное приложение карт
```

Это может быть **Яндекс Карты, 2ГИС** или другой обработчик `geo:` на телефоне. Если подходящего приложения нет, используется веб-страница 2ГИС.

Таким образом основной сценарий HistoryDay не зависит от API-ключа картографического сервиса и продолжает работать без встроенной онлайн-карты.

### Подписи в итоговом видео

Перед пересборкой ролика можно выбрать оформление каждого момента:

- `время + место`;
- `время`;
- `место`;
- `координаты`;
- без подписи.

Сборка выполняется локально через **Media3 Composition / Transformer**. Фрагменты декодируются и заново кодируются в единый H.264/AAC-поток, что делает итоговый MP4 стабильнее прямой склейки отдельных сжатых клипов.

## Приватность

HistoryDay спроектирован как локальное приложение.

- Клипы находятся во внутреннем хранилище приложения.
- Дневные ролики собираются на телефоне.
- Собственного backend-сервера нет.
- Аккаунт не создаётся.
- Геолокация не отслеживается постоянно.
- Координата запрашивается только для момента съёмки.
- Доступ к геолокации необязателен — без него приложение продолжает работать как обычный видеодневник.
- Встроенная схема дня не загружает сетевые тайлы.

## Хранение данных

```text
files/videos/
├── clips/
│   └── YYYY-MM-DD/
│       ├── <timestamp>.mp4
│       ├── <timestamp>.mp4
│       └── ...
└── days/
    ├── YYYY-MM-DD.mp4
    └── ...
```

Метаданные моментов — время, путь к файлу и необязательные геоданные — хранятся локально через Room.

## Разрешения Android

Приложение использует только разрешения, необходимые для базовых функций:

- `CAMERA` — запись момента;
- `RECORD_AUDIO` — звук в клипе;
- `POST_NOTIFICATIONS` — напоминания на Android 13+;
- `RECEIVE_BOOT_COMPLETED` — восстановление расписания после перезагрузки;
- `ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION` — необязательная геометка момента;
- `INTERNET` — системные сетевые функции/внешнее открытие веб-карты.

Фоновое разрешение геолокации не используется.

## Сборка из исходников

Требуется:

- JDK 17;
- Android SDK Platform 35;
- Windows 10/11 для готового PowerShell-скрипта либо стандартная Android/Gradle-среда на другой ОС.

### Windows

```powershell
git clone https://github.com/Mika-dot/HistoryDay.git
cd HistoryDay
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\build_dayflash.ps1"
```

Готовый debug APK:

```text
app\build\outputs\apk\debug\app-debug.apk
```

Сразу установить на подключённый через ADB телефон:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\build_dayflash.ps1" -Install
```

### Gradle

```bash
gradle --no-daemon testDebugUnitTest assembleDebug
```

или при наличии wrapper:

```powershell
.\gradlew.bat clean assembleDebug
```

## Ограничение Android

Android не позволяет обычному приложению произвольно включать камеру из фонового режима без действия пользователя.

Поэтому HistoryDay использует минимально возможный сценарий:

```text
уведомление → пользователь нажал → камера → автоматические 2 секунды
```

После нажатия отдельная кнопка «Запись» не требуется.

## Философия проекта

HistoryDay специально не превращается в большую систему ведения дневника.

Ценность приложения в трёх свойствах:

**случайность → минимальное действие → накопление истории.**

Через недели и месяцы получается архив обычной жизни: дорога, работа, люди, места, случайные события — именно те моменты, которые обычно никто специально не снимает.
