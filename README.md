# HistoryDay / «История дня»

Android-приложение, которое превращает случайные двухсекундные фрагменты в короткое видео-воспоминание за день.

## Возможности

- одно уведомление в случайную минуту каждого активного часа с 08:00 до 22:59;
- одно нажатие по уведомлению — без дополнительной кнопки записи;
- фронтальная камера используется по умолчанию, чтобы основной фокус был на лице;
- постоянный выбор фронтальной или задней камеры на главном экране;
- быстрое переключение камеры прямо на экране записи;
- зеркальная фронтальная запись, совпадающая с привычным селфи-превью;
- автоматическая запись HD-видео длительностью 2 секунды;
- локальное хранение, карточки дней и превью первого момента;
- автоматическая ночная сборка ролика предыдущего дня;
- лёгкая цветокоррекция финального ролика: насыщенность +12 и светлота +2 через Media3 Transformer;
- просмотр, пересборка и отправка MP4 через системное меню Android.

## Сборка через PowerShell

Требования: JDK 17, Android SDK Platform 35.

```powershell
cd C:\Users\PerestoroninAM\Downloads\DayFlash
.\gradlew.bat assembleDebug
```

APK:

```text
app\build\outputs\apk\debug\app-debug.apk
```

Установка на подключённый телефон:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r ".\app\build\outputs\apk\debug\app-debug.apk"
```

## Стек

- Kotlin, Android SDK 35, minSdk 26;
- CameraX 1.4.1;
- Room 2.6.1;
- WorkManager 2.10.0;
- Media3 Transformer / Effect 1.10.1;
- Material 3.

## Ограничение Android

Android не позволяет незаметно включать камеру из фонового режима. Запись запускается после явного нажатия пользователя на уведомление. После первого предоставления разрешений дополнительных подтверждений нет.

## Хранение

- исходные клипы: `files/videos/clips/YYYY-MM-DD/`;
- дневные ролики: `files/videos/days/YYYY-MM-DD.mp4`.

Все материалы остаются на устройстве, пока пользователь сам не отправит или не экспортирует ролик.
