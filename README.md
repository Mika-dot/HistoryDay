# HistoryDay — «История дня»

HistoryDay — Android-приложение, которое несколько раз в течение дня предлагает записать короткий двухсекундный момент, а затем собирает эти фрагменты в видео-воспоминание за день.

Всё хранится и обрабатывается локально на телефоне: аккаунт, сервер и облачная загрузка не требуются.

## Что уже реализовано

- уведомление приходит один раз в случайную минуту каждого активного часа;
- активное окно по умолчанию: с `08:00` до `22:59`;
- после нажатия на уведомление камера открывается без дополнительной кнопки подтверждения;
- запись начинается автоматически после короткого прогрева камеры;
- длительность каждого фрагмента — 2 секунды;
- после записи экран камеры закрывается;
- фронтальная камера выбрана по умолчанию;
- фронтальная запись зеркальная, как привычное селфи;
- на главном экране можно сохранить выбор фронтальной или задней камеры;
- камеру можно переключить прямо на экране записи;
- фрагменты группируются по дням;
- карточка дня показывает дату, количество моментов и превью;
- ролик дня можно собрать, пересобрать, посмотреть и отправить через системное меню Android;
- при сборке ролика применяется лёгкая цветокоррекция: насыщенность `+12`, светлота `+2`;
- автоматическая сборка ролика предыдущего дня запланирована примерно на `00:10`;
- расписание уведомлений восстанавливается после перезагрузки телефона.

## Требования для сборки

- Windows 10/11;
- JDK 17;
- Android SDK Platform 35;
- подключение к интернету при первой сборке для загрузки Gradle и зависимостей;
- Android 8.0 или новее (`minSdk 26`).

Проект использует:

- Kotlin 2.0.21;
- Android Gradle Plugin 8.7.3;
- Gradle 8.9;
- CameraX 1.4.1;
- Room 2.6.1;
- WorkManager 2.10.0;
- Media3 Transformer / Effect 1.10.1;
- Material 3.

## Скачать проект

```powershell
git clone https://github.com/Mika-dot/HistoryDay.git
cd HistoryDay
```

Либо скачайте репозиторий через **Code → Download ZIP** и распакуйте его.

## Первая сборка через PowerShell

В корне проекта находится `build_dayflash.ps1`. Скрипт:

1. находит Android SDK;
2. находит установленный JDK 17;
3. создаёт `local.properties`;
4. при отсутствии Gradle Wrapper скачивает Gradle 8.9 и создаёт wrapper;
5. выполняет чистую debug-сборку.

Запуск:

```powershell
Set-Location "C:\Users\PerestoroninAM\Downloads\HistoryDay"
powershell.exe -ExecutionPolicy Bypass -File ".\build_dayflash.ps1"
```

Готовый APK:

```text
app\build\outputs\apk\debug\app-debug.apk
```

## Последующие сборки

После первого запуска скрипта появятся `gradlew.bat` и папка `gradle/wrapper`.

```powershell
.\gradlew.bat assembleDebug
```

Полная очистка и пересборка:

```powershell
.\gradlew.bat clean assembleDebug
```

## Сборка и установка на телефон

На телефоне включите **Параметры разработчика → Отладка по USB**, подключите его кабелем и выполните:

```powershell
powershell.exe -ExecutionPolicy Bypass -File ".\build_dayflash.ps1" -Install
```

Либо установите уже собранный APK вручную:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r ".\app\build\outputs\apk\debug\app-debug.apk"
```

## Сборка через Android Studio

1. Откройте корень репозитория как проект.
2. Выберите JDK 17 для Gradle.
3. Дождитесь Gradle Sync.
4. Выберите **Build → Build APK(s)**.

Для публикации релиза используйте **Build → Generate Signed Bundle / APK** и собственный keystore. Подписанный ключ в репозиторий не добавляется.

## Первый запуск

Приложение запросит:

- доступ к камере;
- доступ к микрофону;
- разрешение на уведомления на Android 13 и новее.

После выдачи разрешений нажмите **«Включить моменты»**. Кнопка с камерой на главном экране позволяет сразу проверить двухсекундную запись, не ожидая уведомления.

## Структура проекта

```text
app/src/main/java/com/example/dayflash/
├── capture/   экран CameraX, автоматическая запись, выбор камеры
├── data/      Room-база клипов и группировка по дням
├── notify/    уведомления и случайное расписание AlarmManager
├── ui/        главный экран, карточки дней, просмотр ролика
├── video/     объединение MP4 и цветокоррекция Media3
└── worker/    ночная автоматическая сборка WorkManager

app/src/main/res/
├── drawable/  фон, иконки и визуальные элементы
├── layout/    XML-интерфейсы экранов
├── values/    цвета, строки, темы и стили
└── xml/       FileProvider paths
```

## Где хранятся видео

Во внутренней папке приложения:

```text
files/videos/clips/YYYY-MM-DD/   исходные двухсекундные клипы
files/videos/days/YYYY-MM-DD.mp4 итоговые ролики дня
```

Другие приложения не получают к ним доступ автоматически. При нажатии **«Поделиться»** конкретный ролик передаётся выбранному приложению через `FileProvider`.

## Важное ограничение Android

Android не разрешает приложению незаметно включать камеру из фонового режима. Поэтому запись начинается после явного нажатия пользователя на уведомление. После этого дополнительных подтверждений или нажатия на кнопку записи не требуется.

## Изменение поведения

Основные параметры находятся здесь:

- длительность записи — `CaptureActivity.kt`, константа `RECORDING_MS`;
- время работы уведомлений — `ReminderScheduler.kt`, `startHour` и `endHour`;
- диапазон случайной минуты — `ReminderScheduler.kt`, `Random.nextInt(4, 56)`;
- сила цветокоррекции — `ColorGradeProcessor.kt`;
- время ночной сборки — `DailyWork.kt`.
