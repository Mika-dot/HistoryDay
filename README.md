# HistoryDay — «История дня»

Android-приложение для автоматического дневного видеодневника. В течение дня приложение присылает уведомления, по нажатию записывает двухсекундный клип, а затем собирает все клипы дня в один ролик.

## Возможности

- уведомление один раз в случайную минуту каждого часа;
- рабочий интервал по умолчанию: `08:00–22:59`;
- запись начинается автоматически после нажатия на уведомление;
- длительность фрагмента — 2 секунды;
- фронтальная камера используется по умолчанию;
- переключение между фронтальной и задней камерой;
- выбранная камера сохраняется;
- фронтальная запись зеркальная;
- качество записи: FHD с автоматическим переходом на HD/SD при необходимости;
- карточки дней с количеством фрагментов и превью;
- просмотр, пересборка и отправка дневного ролика;
- локальное хранение без сервера и аккаунта;
- восстановление расписания после перезагрузки телефона.

## Склейка видео

Начиная с версии `1.2`, ролик собирается через `Media3 Composition`.

Каждый клип помещается в последовательную временную шкалу, декодируется и заново кодируется в единый поток H.264/AAC. Это устраняет зависание изображения после первого клипа, которое возникало при прямом копировании сжатых кадров через `MediaMuxer`.

Цветовые фильтры к ролику не применяются. Исходная цветопередача камеры сохраняется.

## Требования

- Windows 10/11;
- JDK 17;
- Android SDK Platform 35;
- Android 8.0 или новее (`minSdk 26`);
- интернет при первой сборке.

## Скачать

```powershell
git clone https://github.com/Mika-dot/HistoryDay.git
cd HistoryDay
```

Либо используйте **Code → Download ZIP**.

## Сборка через PowerShell

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\build_dayflash.ps1"
```

Скрипт найдёт JDK и Android SDK, создаст `local.properties`, при необходимости установит Gradle Wrapper и соберёт debug APK.

Готовый файл:

```text
app\build\outputs\apk\debug\app-debug.apk
```

Сборка и установка на подключённый телефон:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\build_dayflash.ps1" -Install
```

Последующие сборки:

```powershell
.\gradlew.bat clean assembleDebug
```

## Сборка через Android Studio

1. Откройте корень репозитория.
2. Выберите JDK 17 для Gradle.
3. Дождитесь Gradle Sync.
4. Выполните **Build → Build APK(s)**.

Для релизной сборки используйте **Build → Generate Signed Bundle / APK** и собственный keystore.

## Структура

```text
app/src/main/java/com/example/dayflash/
├── capture/   CameraX и автоматическая запись
├── data/      Room-база фрагментов
├── notify/    уведомления и расписание
├── ui/        основные экраны
├── video/     сборка ролика Media3 Composition
└── worker/    ночная сборка WorkManager
```

## Хранение

```text
files/videos/clips/YYYY-MM-DD/   исходные клипы
files/videos/days/YYYY-MM-DD.mp4 дневные ролики
```

## Настройки в коде

- длительность записи: `CaptureActivity.kt`, `RECORDING_MS`;
- рабочие часы: `ReminderScheduler.kt`, `startHour` и `endHour`;
- случайная минута: `ReminderScheduler.kt`, `Random.nextInt(4, 56)`;
- время ночной сборки: `DailyWork.kt`.

## Ограничение Android

Android не разрешает включать камеру скрытно из фонового режима. Поэтому пользователь должен нажать на уведомление. После нажатия дополнительных подтверждений и кнопки записи нет.
