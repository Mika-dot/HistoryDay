# HistoryDay — «История дня»

Минималистичный Android-видеодневник: приложение один раз в случайный момент каждого часа предлагает сохранить **2 секунды жизни**, а затем собирает эти фрагменты в короткую историю дня.

Главный принцип проекта — **минимум действий и минимум зависимостей**. Нет аккаунта, облака, ленты, обязательного интернета или постоянного фонового трекинга.

## Что умеет версия 1.5

### Съёмка без лишних действий

- уведомление один раз в случайную минуту каждого часа;
- рабочий интервал по умолчанию: `08:00–22:59`;
- нажатие на уведомление сразу открывает камеру и запускает запись;
- длительность одного момента — 2 секунды;
- фронтальная камера используется по умолчанию;
- переключение на заднюю камеру в один тап;
- выбранная камера запоминается;
- фронтальная запись зеркальная;
- FHD с автоматическим fallback на HD/SD.

### Уведомления, которые не мешают

У напоминания появились быстрые действия:

- **Через 10 минут** — переносит текущий момент;
- **Пропустить** — закрывает напоминание и оставляет обычное расписание дальше.

Никакого отдельного экрана планировщика для этого не требуется.

### История каждого дня

Для каждого дня приложение показывает:

- итоговый ролик;
- число сохранённых моментов;
- горизонтальную шкалу времени;
- полную хронологию клипов;
- время каждого момента;
- место и координаты, если пользователь разрешил геолокацию;
- офлайн-схему последовательности геоточек дня.

Нажатие на момент сразу воспроизводит именно этот двухсекундный фрагмент.

### География без тяжёлого картографического SDK

HistoryDay **не встраивает Google Maps, OSM/osmdroid, Yandex MapKit или 2GIS SDK**.

Вместо этого:

1. координата запрашивается только во время сохранения момента;
2. название места определяется системным `Geocoder` Android, если он доступен;
3. внутри приложения рисуется лёгкая офлайн-схема точек дня без загрузки тайлов;
4. кнопка **«Открыть точку в картах»** использует стандартный Android `geo:` intent — точка откроется в установленном приложении карт (например, Яндекс Картах или 2ГИС);
5. если на устройстве нет обработчика `geo:`, используется веб-страница 2ГИС.

Это сохраняет приложение маленьким и не привязывает основной сценарий к API-ключу конкретного поставщика карт.

### Оформление дневного ролика

Перед пересборкой можно выбрать подпись для каждого фрагмента:

- время + место;
- только время;
- только место;
- координаты;
- без подписи.

Склейка выполняется локально через `Media3 Composition` с единым H.264/AAC потоком.

## Приватность

Базовый сценарий полностью локальный:

- аккаунт не нужен;
- сервер HistoryDay не используется;
- клипы и готовые ролики хранятся только в памяти приложения;
- геолокация не собирается постоянно в фоне;
- разрешение `ACCESS_BACKGROUND_LOCATION` не используется;
- карта внутри приложения не загружает сетевые тайлы;
- разрешение геолокации можно не выдавать — видеодневник продолжит работать без геометок.

## Хранение

```text
files/videos/clips/YYYY-MM-DD/   исходные 2-секундные клипы
files/videos/days/YYYY-MM-DD.mp4 итоговые ролики
```

Метаданные моментов хранятся в локальной Room-базе.

## Технологии

- Kotlin;
- Android SDK 35;
- CameraX;
- Media3 / Transformer / ExoPlayer;
- Room;
- WorkManager;
- Material Components;
- стандартный `LocationManager` и системный `Geocoder` Android.

Минимальная версия Android: **8.0 (API 26)**.

## Архитектура

```text
app/src/main/java/com/example/dayflash/
├── capture/   CameraX, 2-секундная автоматическая запись
├── data/      Room-база моментов
├── location/  геоточка момента и запуск внешних карт
├── notify/    расписание, уведомления, snooze/skip
├── ui/        список дней, день, таймлайн, офлайн-схема маршрута
├── video/     сборка дневного ролика Media3 Composition
└── worker/    ночная автоматическая сборка
```

## Сборка

Требуется:

- Windows 10/11;
- JDK 17;
- Android SDK Platform 35;
- интернет при первой загрузке Gradle-зависимостей.

```powershell
git clone https://github.com/Mika-dot/HistoryDay.git
cd HistoryDay
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\build_dayflash.ps1"
```

APK после сборки:

```text
app\build\outputs\apk\debug\app-debug.apk
```

Сборка и установка на подключённый телефон:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\build_dayflash.ps1" -Install
```

Или стандартно:

```powershell
.\gradlew.bat clean assembleDebug
```

## CI

GitHub Actions собирает Android-проект при push/PR. Это позволяет сразу ловить ошибки ресурсов, ViewBinding, Kotlin и Gradle до установки APK на телефон.

## Важное ограничение Android

Android не разрешает приложению произвольно включить камеру скрытно из фонового режима. Поэтому пользователь должен нажать на уведомление. После этого HistoryDay сам открывает камеру и начинает двухсекундную запись без дополнительной кнопки подтверждения.

## Идея проекта

HistoryDay не пытается быть социальной сетью или большим дневником. Его задача проще: несколько случайных двухсекундных срезов дня, которые со временем превращаются в живой архив, а не в специально постановочную съёмку.
